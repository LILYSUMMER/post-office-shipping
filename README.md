# 우체국 송장 도우미

스마트스토어 주문 엑셀을 우체국 창구소포 접수파일로 바꾸고, 우체국에서 받은 등기번호를 스마트스토어 일괄발송 파일로 만들어 주는 웹 도구입니다.

**쓰는 곳 → https://LILYSUMMER.github.io/post-office-shipping/**

## 하는 일

1. **스마트스토어 주문 → 우체국 접수파일**
   - 발주/발송관리에서 받은 엑셀을 올리면 우체국 창구소포 양식(.xlsx)으로 바꿔 줍니다.
   - 옵션(또는 상품명)에 따라 중량·부피를 자동으로 넣습니다. 설정에서 고칠 수 있습니다.
   - 수량이 여러 개면 상자 수만큼 줄을 나눕니다.
   - 전화나 메모로 받은 주문도 직접 입력해 같은 파일에 넣을 수 있습니다.
   - 오늘 보낼 소포가 상품별로 몇 개인지, 총 무게가 얼마인지 보여 줍니다.

2. **우체국 등기번호 → 스마트스토어 일괄발송 파일**
   - 우체국 접수결과 엑셀과 주문 엑셀을 올리면 받는 분 이름·전화번호로 짝을 맞춰 송장번호를 채웁니다.
   - 시트 이름이 `발송처리`인 파일로 저장되니 판매자센터에 그대로 올리면 됩니다.

## 개인정보

엑셀을 읽고 쓰는 일은 모두 **쓰는 사람의 브라우저 안에서만** 일어납니다. 주문 파일이 서버로 올라가지 않고, 저장되지도 않습니다. 설정값과 직접 입력한 주문만 그 브라우저에 남습니다.

## 인터넷 없이 쓰기

`index.html` 파일 하나만 내려받아 더블클릭하면 똑같이 동작합니다. 맥, 윈도우 모두 됩니다.
